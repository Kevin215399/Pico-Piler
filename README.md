Pico-Piler

I made the Pico-Piler! 
The Pico-Piler is a compiler designed to translate C code into Risc-V assembly. 
This is important because CPU's can't understand high level languages, and they must first be converted into assembly. 

The compiler includes arithmetic, control flow, variables, functions, pointers, standard functions, and more! 

I learned a lot about how compilers work through this event, and I am very happy with my first ever compiler!
